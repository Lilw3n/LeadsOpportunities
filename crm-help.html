FAQ rapide

Comment envoyer un paiement ou un abonnement Stripe ?

Ouvrez Stripe — envoyer & payer, choisissez paiement unique ou abonnement, générez le lien, puis copiez-le (ou utilisez la messagerie pour l’insérer dans un e-mail).

Comment simuler un client externe ?

Ouvrez Modes test, choisissez Test ou Externe — le dashboard client s'ouvre avec bannière simulation.

Où créer un devis complet (produit → client → véhicule) ?

Utilisez le wizard nouveau devis, calqué sur /dashboard/quotes/new multisite.

Comment analyser un RIB ou une carte grise ?

Page IA & suggestions — collez le texte OCR ou URL Drive.

Comment créer un contrat d'assurance ?

Utilisez le wizard nouveau contrat (produit → client / interlocuteur), calqué sur le multisite.
