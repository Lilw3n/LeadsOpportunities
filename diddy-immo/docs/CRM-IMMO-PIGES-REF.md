# Piges immo — référence UI (inspiration métier)

Écrans de référence fournis par le métier (pas liés aux barèmes / honoraires).

## Panneau filtres « PIGES »

Sections verticales :

1. **RECHERCHE** — mots-clés, état, statut, classif projet, à contacter, contact connu, téléphone (oui / indifférent / non)
2. **OÙ ?** — localité, géolocalisation
3. **QUI ?** — agence, suivi par
4. **QUOI ?** — type de bien, transaction (à vendre / à louer), origine (Leboncoin, SeLoger…), pièces de→à, chambres de→à, prix de→à, surface de→à, actions depuis date
5. **QUAND ?** — date début / date fin  
Bouton bas : **RECHERCHER**
