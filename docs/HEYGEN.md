# HeyGen — contenu video pour reseaux sociaux

1. Rediger un script court (30–60 s) depuis un article du [blog](../blog/).
2. Generer la video sur [HeyGen](https://app.heygen.com/).
3. Publier sur LinkedIn / YouTube Shorts avec UTM `utm_source=social&utm_medium=heygen`.
4. Lier vers la landing ou la page SEO ville correspondante.

Automatisation future : webhook fin de rendu → Make → brouillon publication.
