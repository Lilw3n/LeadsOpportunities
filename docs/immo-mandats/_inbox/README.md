# Inbox — PDF mandats / comparatifs réseau

Déposez ici les PDF fournis par le réseau (ex. `comparatif_differentes-formes_des_mandats.pdf`).

Ces fichiers servent à **enrichir** `data/immo-mandat-formes.json` :

- garder ce qui est **général** (loi Hoguet, formes Simple / Exclusif / Semi-exclusif) ;
- taguer `audience: "agence"` tout ce qui est spécifique au réseau (packs, co-listing, honoraires réduits vente directe, délais de publication).

Ne pas scraper / ne pas committer de documents confidentiels clients — uniquement supports formation / modèles anonymisés.
