# Inbox — PDF mandats / comparatifs réseau

Déposez ici les PDF fournis par le réseau, par exemple :

- `comparatif_differentes-formes_des_mandats.pdf`
- `mandat_de_vente_sans_exclusivite_*.pdf` (ex. modèle type Laforêt)

Ces fichiers servent à **enrichir** :

- `data/immo-mandat-formes.json` (comparatif formes)
- `data/immo-mandat-vente-simple-form.json` (formulaire sans exclusivité)

Règles :

- garder ce qui est **général** (loi Hoguet, sans exclusivité) ;
- taguer `audience: "agence"` tout usage réseau ;
- **ne jamais figer** une enseigne dans le formulaire CRM — le bloc mandataire reste à compléter par l’utilisateur (agence de son choix).

Ne pas committer de documents confidentiels clients — uniquement supports formation / modèles anonymisés.
